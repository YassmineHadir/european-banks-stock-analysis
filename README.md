
#  European Banks Stock Analysis

A comparative financial analysis of three major European banks listed on European stock exchanges, combining Python data analysis with financial visualizations.

##  Project Goal

Analyze and compare the stock performance, returns, and volatility of three major European banks over a 2-year period (April 2024 – April 2026) to evaluate their risk-adjusted returns and inform investment perspectives.

##  Banks Analyzed

- **BNP Paribas** (BNP.PA) — France 🇫🇷
- **Société Générale** (GLE.PA) — France 🇫🇷
- **Banco Santander** (SAN.MC) — Spain 🇪🇸

##  Tools & Technologies

- **Python** (pandas, matplotlib, yfinance) — data collection and analysis
- **Jupyter Notebook** (Google Colab) — development environment
- **Excel / CSV** — data storage and supporting calculations

##  Key Findings

Sur les deux dernières années, SocGen a surperformé BNP et Santander avec un rendement cumulé de +198% contre +60% et +143%, pour une volatilité comparable ce qui suggère que la hausse a été portée par un vrai re-rating du titre plutôt que par une prise de risque disproportionnée

##  How to Reproduce

1. Clone or download this repository
2. Open `European_Banks_Analysis.ipynb` in Jupyter or Google Colab
3. Run all cells — data is automatically downloaded via the `yfinance` library
4. The notebook reproduces all visualizations and metrics

##  Skills Demonstrated

- Financial data acquisition via APIs (yfinance / Yahoo Finance)
- Data manipulation and cleaning with **pandas**
- Computation of financial metrics (daily returns, cumulative returns, annualized volatility)
- Data visualization with **matplotlib**
- Risk-adjusted performance analysis (Return / Risk ratio)
